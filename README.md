# 우리집 TV 리모컨 (LG webOS)

같은 Wi-Fi 안에서 핸드폰으로 LG TV를 조작하는 안드로이드 앱입니다. 서버와 계정이 필요 없습니다.

## APK 받기
GitHub에 올리면 Actions가 자동으로 빌드합니다.
저장소 오른쪽의 **Releases**에서 `tv-remote.apk`를 받으세요.

## 처음 연결
1. TV를 켜고 핸드폰을 집 Wi-Fi에 연결합니다.
2. 앱을 열면 TV를 자동으로 찾습니다. 못 찾으면 설정 → 주소 직접 입력을 누릅니다.
   (TV 설정 → 네트워크에서 IP 확인)
3. TV 화면에 연결 요청이 뜨면 **허용**을 누릅니다. 핸드폰마다 한 번씩 하면 됩니다.

## TV 켜기 버튼
- TV 설정에서 **"Wi-Fi로 TV 켜기"**(또는 "모바일로 TV 켜기")를 켜두세요.
- 앱이 TV에 한 번 연결되면 켜기 기능이 자동으로 준비됩니다.
